# KDP Publishing Checklist

## Before Upload

### Categories
- [ ] Select 2 most relevant sub-categories (e.g., Philosophy > Existentialism, Self-Help > Personal Transformation)
- [ ] Do NOT leave any suitable category unfilled

### Keywords (7 slots)
- [ ] Use full phrases, not single words (e.g., "digital loneliness book" not "loneliness")
- [ ] Include identity + pain point combos (e.g., "gen z meaning crisis")
- [ ] Mix English and Chinese keywords for bilingual markets
- [ ] No keyword stuffing or irrelevant terms (KDP policy violation)

### Pricing
- [ ] Set $2.99–$4.99 to qualify for 70% royalty
- [ ] Consider $0.99 launch promo for initial review velocity
- [ ] Reference comparable titles for market-aligned pricing

### Cover
- [ ] 2560 x 1600 pixels recommended, minimum 1000 x 1600
- [ ] RGB color mode, professional thumbnail readability
- [ ] Disclose AI-generated cover if applicable

### Format
- [ ] EPUB with embedded chapter metadata (Pandoc YAML)
- [ ] Test on Kindle Previewer before upload
- [ ] Short paragraphs, sub-headings for mobile reading

### Content Specs
- [ ] Total word count: 20,000–40,000
- [ ] Per chapter: 3,000–5,000 words
- [ ] Flesch Reading Ease ≥ 60 (secondary school level)

## Content Policy Compliance
- [ ] No copyrighted material
- [ ] No hate speech, extreme political content, adult content
- [ ] Factual claims backed by sources or framed as opinion
- [ ] No competitor titles in keywords or description

## AI Disclosure
- [ ] Check "AI-generated content" box if applicable
- [ ] Include disclosure statement in front matter

## Post-Publication
- [ ] Monitor BSR and reviews
- [ ] A/B test price points
- [ ] Plan series expansion based on reader feedback
