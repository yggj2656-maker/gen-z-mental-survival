# Quality Check Framework

## Per Chapter

### Consistency
- [ ] Terminology matches across all chapters
- [ ] Examples and metaphors don't contradict
- [ ] Tone stays casual, Gen Z, non-academic

### Readability
- [ ] Flesch Reading Ease ≥ 60
- [ ] Short paragraphs (3–5 sentences max)
- [ ] Active voice dominant
- [ ] Sub-headings for scan-ability

### Content Quality
- [ ] Each chapter solves ONE real problem
- [ ] Problem → definition → psychology → philosophy → examples → solution → summary → exercises
- [ ] No AI filler phrases
- [ ] No fake deep / pseudo-profound statements
- [ ] All statistics and claims verifiable

## Full Manuscript

### Structural
- [ ] Chapter count 6–8
- [ ] Total word count 20,000–40,000
- [ ] Per chapter 3,000–5,000 words

### Anti-Plagiarism
- [ ] No copied passages from known books
- [ ] Source citations for referenced data
- [ ] AI disclosure statement in front matter

### Hallucination Detection
- [ ] Verify all statistics against source
- [ ] Check concept explanations against Wikipedia/reference
- [ ] Flag any unsupported factual claims

### Reader Experience
- [ ] Opening hook grabs attention
- [ ] Each chapter ends with actionable exercise
- [ ] Gamified elements feel earned, not gimmicky
- [ ] Reader should feel understood, not lectured

## KDP Readiness
- [ ] AI disclosure included
- [ ] 7 keywords prepared
- [ ] 2 categories selected
- [ ] Cover design brief ready
- [ ] Book description written
- [ ] Author bio written
