# 极简风 — Composition

## 整体布局
- 6×9 英寸纵向
- 所有元素居中
- 这是封面设计里最难的一种——因为少到极致，所以每个像素都不能错

## 方案 A（暗底）布局
```
[25% 空白]

ALWAYS ONLINE,        ← 粗体，中心
NEVER HERE            ← 粗体，中心

[~5% 空间]

————————————————     ← 极细横线，中间有微小的断裂（琥珀色）

[~8% 空间]

A Philosophy of Attention,   ← 轻字重，小
Presence, and Survival
for the Exhausted Generation

[剩余空间]

MOON                  ← 轻字重，底部居中，距底 8%
```

## 方案 B（白底）布局
- 与方案 A 相同，但去掉横线
- 纯文字——只有标题、副标题、作者名
- 所有内容在垂直方向上更居中（上下空白更均衡）

## 横线的断裂（方案 A 专属细节）
- 横线总宽度约为主标题字宽的 50%
- 断裂位置在线的中心
- 断裂宽度约 2-3mm（在 6 英寸封面上约 10-15px）
- 断裂的两端略微上翘或下弯（像信号干扰），或保持平直
- 这个缺口是全封面唯一的"图形"，承载全部隐喻：信号中断、联系断裂、注意力衰减

## 安全区域
- 文字距裁切线至少 0.25 英寸
- 标题左右留白至少各 0.75 英寸

## 视觉层次
1. 标题（压倒性）
2. 横线（如果有的话——视线停顿点）
3. 副标题（可有可无的补充）
4. 作者名（最低调的存在）
