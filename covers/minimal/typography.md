# 极简风 — Typography

## 这是封面唯一的设计元素。排版必须完美。

## 标题字体
- **风格**: 经典 grotesk 或 neo-grotesk 无衬线
- **推荐**: Helvetica Neue / Neue Haas Grotesk / Untitled Sans / Suisse Int'l
- **字重**: Medium 或 Bold（不能用 Light——太弱）
- **字号**: 占据封面宽度的 65-75%
- **字间距**: Tight (-20 到 -30 tracking)，经典 grotesk 的感觉
- **行距**: Tight (1.0–1.05)，行与行之间几乎没有空隙

## 排版
```
ALWAYS ONLINE,
NEVER HERE
```
两行，或者三行：
```
ALWAYS
ONLINE,
NEVER HERE
```

## 副标题
- 同字体系列，Light 字重
- 字号约为主标题的 18-20%
- 放在标题下方，间距约 1.5 倍标题行距
- 可以单行或两行
- 颜色比标题浅

## 作者名
- 同字体，Light 或 Regular
- 底部居中或底部偏一侧
- 很小的字号

## 如果加入图形元素
- 一根横线，宽度不超过标题文字宽度的 60%
- 或一个极小的圆点/方块（直径约 3-5px）
- 颜色用琥珀 `#E87A3E`（暗底）或深灰 `#333`（白底）
- 放在标题上方或下方，与文字保持距离

## 排版细节
- 所有文字严格居中
- 左右边距相等且充足（至少占页面宽度的 15% 作为边距）
- 标题在垂直方向上也居中或略偏上（视觉中心而非数学中心）
- 如果感觉太"空"，加 letter-spacing 而不是加元素

## 绝对不能
- 任何装饰线、花体、连字特效
- 阴影、浮雕、渐变
- 多种字体混搭
- 斜体（除非有充分理由）
