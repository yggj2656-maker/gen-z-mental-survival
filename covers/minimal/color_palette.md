# 极简风 — Color Palette

## 方案 A：暗底（Dark Mode）

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景 | `#0C0C0E` | 全幅背景 |
| 标题 | `#EDEAE4` — 暖米白 | 书名 |
| 副标题 | `#9E9A93` — 暖灰 | 副标题 |
| 作者 | `#75726C` — 中灰 | 作者名 |
| 点缀线/点 | `#E87A3E` — 暗琥珀 | 可选的唯一图形元素 |

## 方案 B：白底（Light Mode）

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景 | `#F4F2ED` — 暖灰白 | 全幅背景 |
| 标题 | `#1A1A1A` — 近黑 | 书名 |
| 副标题 | `#5C5A56` — 深灰 | 副标题 |
| 作者 | `#8A8782` — 中灰 | 作者名 |
| 点缀线/点 | `#333333` — 深灰 | 可选图形元素 |

## 配色原则
- 最多 3-4 个颜色（包括背景色）
- 拒绝任何渐变
- 拒绝任何透明度叠加（除非用于极小点缀）
- 两种方案都控制在单色系范围内
- 暖色调：文字和背景都有微弱暖底，避免冰冷
