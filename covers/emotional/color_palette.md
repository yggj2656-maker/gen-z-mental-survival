# 情绪风 — Color Palette

## 主色调

| 角色 | 色值 | 用途 |
|------|------|------|
| 画面主色 | `#080C14` — 极深夜蓝 | 主调，近黑但不是黑 |
| 渐入亮区 | `#141C28` — 深蓝灰 | 光晕外圈过渡 |
| 光源暖色 | `#E87A3E` — 暗琥珀 | 屏幕光核心 |
| 光源中区 | `#C5693A` — 深琥珀 | 光晕中间层 |
| 光源外区 | `#7A5540` — 暖棕灰 | 光晕最外层，近背景 |
| 冷光点缀 | `#8BAAC4` — 灰蓝 | 极小的冷色平衡 |
| 文字色 | `#E8E4DD` — 暖白偏灰 | 标题 |
| 辅助文字 | `#968E84` — 暖灰 | 副标题/作者 |

## 色彩关系
- 整体是暖琥珀光在冷暗背景上的孤独对话
- 90% 画面是暗调，只有 10% 是光
- 光的颜色偏暖但不是"温暖"——是"远的暖"，像是隔着玻璃看到的烛光
- 加入极细微的蓝灰冷调作为平衡

## 情绪暗示
- 凌晨
- 失眠
- 手机屏幕是唯一的灯
- 潮湿的孤独（不是干燥的抑郁）
- 有人在，但不在这里

## 不要
- 不要霓虹色
- 不要紫色（太 cyberpunk）
- 不要绿色（太 Matrix）
- 不要高饱和
