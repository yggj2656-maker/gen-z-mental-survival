# 商业风 — Typography

## 标题字体
- **风格**: 现代无衬线、粗体、笔画均匀
- **推荐字体**: Inter Bold / Montserrat Bold / Satoshi Bold / DM Sans Bold
- **字号感觉**: 大而自信，但不压过画面
- **字间距**: 略紧，-10 到 -20 tracking
- **行距**: 紧凑，1.0–1.1 倍
- **排版**: 三行堆叠
  ```
  ALWAYS ONLINE,
  NEVER HERE
  ```
  （原始标题较长，封面可以只用主标题，副标题作为小字补充）

## 副标题字体
- **风格**: 同族轻字重或几何人文主义无衬线
- **推荐**: Inter Light / Montserrat Light / Source Sans Pro
- **字号**: 标题的 25-30%
- **颜色**: 比标题更灰（降低对比度）

## 作者名字体
- **风格**: 简洁小号无衬线
- **字号**: 标题的 15-20%
- **位置**: 底部居中，距底边约 8-10% 页面高度
- **颜色**: 与副标题相同或略浅

## 文字布局
```
[空白 — 约 15% 页面高度]

ALWAYS ONLINE,    ← 大号粗体
NEVER HERE        ← 大号粗体

[小间距]

A Philosophy of Attention, Presence,   ← 轻字重
and Survival for the Exhausted Generation

[~50% 视觉空间 — 抽象光元素在这里]

MOON              ← 底部居中
```

## 安全区域
- 所有文字距离裁切边至少 0.25 英寸（KDP 要求）
- 实际可排版区域：约 5.5 × 8.5 英寸
