# 商业风 — Color Palette

## 主色调

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景深色 | `#0B0E14` — 深海軍蓝黑 | 主背景 |
| 背景渐变 | `#141924` → `#0B0E14` | 微妙纵向渐变，上略亮下暗 |
| 标题字色 | `#F2EFE9` — 暖米白 | 书名 |
| 副标题字色 | `#A49F96` — 暖灰 | 副标题 |
| 作者字色 | `#8A8580` — 中灰 | 作者名 |
| 光元素 | `#FF7B3D` — 琥珀橙 | 中心光晕（面积很小） |
| 光元素边缘 | `#5B8CB8` — 淡蓝灰 | 光晕边缘过渡 |

## 配色原则
- 整体呈现"黑暗中的一点暖光"感
- 琥珀色是唯一有彩度的颜色，仅作点缀
- 不要多种颜色——保持克制
- 无纯白文字（伤眼），用暖米白
- 无纯黑色背景（死黑），用有蓝色底调的深灰

## 情绪暗示
- 深夜
- 屏幕光
- 安静
- 内省
- 温暖在远处
